## 문제 설명<br/><br/>
N-Queen 문제는 크기가 N × N인 체스판 위에 퀸 N개를 서로 공격할 수 없게 놓는 문제다. N이 주어졌을 때, 퀸을 놓는 방법의 수를 구하는 프로그램을 작성해야 한다.<br/><br/>

**입력 예시:** `8`<br/><br/>
**출력 예시:** `92` <br/><br/>
**제약:**
- `1 ≤ N < 15` 

## 풀이 전략<br/><br/>
**핵심 아이디어:** 백트래킹(Backtracking)을 이용하여 가능한 모든 배치를 탐색하되, 유망하지 않은 경로는 조기에 차단한다.<br/><br/>
**사용 이유:** N의 최대치가 14로 작기 때문에 완전 탐색 기반의 백트래킹으로 해결 가능하다. 퀸은 같은 행, 열, 대각선에 위치할 수 없다는 조건을 효율적으로 확인하는 것이 핵심이다.<br/><br/>
**구체적 방법:**
- 한 행에 하나의 퀸만 놓을 수 있으므로, 행을 기준으로 재귀 호출을 진행한다.
- 특정 열에 퀸이 이미 있는지 확인하기 위해 `is_used_col` 배열을 사용한다.
- 두 종류의 대각선 방향에 퀸이 있는지 확인하기 위해 `is_used_diag1`, `is_used_diag2` 배열을 사용한다.
    - `/` 방향 대각선: `row + col` 값이 일정하다.
    - `\` 방향 대각선: `row - col` 값이 일정하다. (음수 방지를 위해 `N-1`을 더해준다.)

<br/>
## c++ 코드
```cpp{% raw %}
#include <iostream>

using namespace std;

class NQ
{
public:
    NQ(int n) : n(n), ans(0), is_used_col({}), is_used_diag1({}), is_used_diag2({}) {}

    // 현재 행, 열의 위치가 안전한지 확인
    bool IsSafe(int row, int col)
    {
        if (is_used_col[col] // 같은 열 여부
        || is_used_diag1[row + col] // '/' 방향 대각선 여부
        || is_used_diag2[row - col + n - 1]) return false; // '\' 방향 대각선 여부
        return true;
    }

    void CheckQueen(int row)
    {
        // 가지치기
        if (row == n)
        {
            ans++;
            return;
        }

        for (int col = 0; col < n; ++col)
        {
            if (IsSafe(row, col))
            {
                // 열, 대각선 배치 여부 체크
                is_used_col[col] = true;
                is_used_diag1[row + col] = true;
                is_used_diag2[row - col + n - 1] = true;

                // 다음 행으로 재귀
                CheckQueen(row + 1);

                // 백트래킹
                is_used_col[col] = false;
                is_used_diag1[row + col] = false;
                is_used_diag2[row - col + n - 1] = false;
            }
        }
    }

    int GetCount()
    {
        CheckQueen(0);
        return ans;
    }

private:
    bool is_used_col[15]; // 같은 열
    bool is_used_diag1[30]; // '/' 방향 대각선 (row+col)
    bool is_used_diag2[30]; // '\' 방향 대각선 (row-col+n-1)
    int n;
    int ans;
};


int main()
{
    int n;
    cin >> n;
    NQ nq(n);
    cout << nq.GetCount();
    return 0;
}
{% endraw %}
```

## 해설
- 단계별 과정:
    1. `CheckQueen(row)` 함수는 현재 `row`번째 행에 퀸을 놓을 위치를 결정한다.
    2. 0번 열부터 `N-1`번 열까지 순회하며 해당 위치가 안전한지 검사한다.
    3. `is_used_col`, `is_used_diag1`, `is_used_diag2` 배열을 참조하여 `O(1)` 시간에 충돌 여부를 판단한다.
    4. 안전하다면 퀸을 배치하고 다음 행인 `CheckQueen(row + 1)`을 호출한다.
    5. 재귀가 끝나고 돌아오면 방금 놓았던 퀸의 자리를 비워주어 다른 가능성을 탐색할 수 있게 한다.
- 예외 처리:
    - N이 1일 때는 1을 출력하며 정상 작동한다.

## 시간복잡도
- 퀸을 놓는 방식의 상한은 O(N!)이다. 실제로는 가지치기(Pruning) 덕분에 이보다 훨씬 적은 수의 노드를 방문하지만, N=14까지의 범위 내에서 제한 시간(10초) 안에 충분히 통과할 수 있다.

## 마치며
N-Queen 문제는 백트래킹의 가장 대표적인 연습 문제다. 대각선 인덱스를 `row + col`과 `row - col + N - 1`로 매핑하여 상수의 시간 복잡도로 유망성을 체크하는 기법을 익히기에 좋다.
